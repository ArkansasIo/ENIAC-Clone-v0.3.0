# Operator Panel Concept

The operator panel is a documentation-first layout for a future graphical front end.

## Display regions
- **Machine state:** stopped, running, faulted.
- **Cycle counter:** current deterministic software-cycle count.
- **Accumulator bank:** inspect signed decimal values and flags.
- **Program controls:** load, start, stop, reset.
- **Event trace:** ordered machine lifecycle and execution messages.

This concept is not an archival reproduction of the original ENIAC console.
