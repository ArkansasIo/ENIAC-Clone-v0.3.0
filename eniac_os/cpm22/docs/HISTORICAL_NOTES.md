# Historical and compatibility notes

CP/M 2.2 was an operating system for 8-bit microcomputers commonly built around the Intel 8080 and compatible processors. Its familiar software layers included the Console Command Processor (CCP), Basic Disk Operating System (BDOS), and Basic Input/Output System (BIOS).

ENIAC was a much earlier electronic decimal calculator programmed using physical switches, cables, and function units. It did not run CP/M, an Intel 8080, or a conventional disk operating system. This repository combines an ENIAC-inspired decimal-machine simulator with a modern CP/M-inspired command shell as an educational comparison.

No proprietary CP/M binary images are included. The command interface is a small subset designed for this simulator, not a reimplementation of the CP/M binary ABI.
