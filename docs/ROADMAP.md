# Roadmap

## Next development stages
1. Add a pulse scheduler and explicit event ordering.
2. Represent arithmetic units as separately configurable machine components.
3. Model program control and repeat mechanisms with testable state machines.
4. Add simulated card-reader, card-punch, and printer peripherals.
5. Expand unit and integration test coverage, including invalid states and boundary values.
6. Build a cross-platform operator console or GUI.
7. Add citations to technical and archival sources for historical behaviors.

## Non-goals for the current version
The current version is not a cycle-accurate electrical emulator and does not claim complete historical fidelity.
